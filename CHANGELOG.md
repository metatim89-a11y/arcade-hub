# Arcade Hub Changelog

## v0.0.47 - 2026-08-21

Version reconciliation release. The displayed version had remained at v0.0.34 while 13 subsequent commits landed on `master`. This release advances the displayed version one patch step per post-v0.0.34 commit: 0.0.34 + 13 = 0.0.47.

### Changes since v0.0.34

- `a648e29` - Redesigned the interface with the Deep Onyx & Amber Titanium glass system.
- `67a9976` - Smoothed the arcade carousel, fixed 3D Mancala, improved BlockDrop controls, and added Neon Hopper.
- `5933782` - Added the unified store, coin packages, arcade landing faucet, and rule sets.
- `d734afc` - Refined the game rosters to five games per category and added touch/sound upgrades.
- `428d9d7` - Added micro-tip coin packages, Crypto Pay modal, and responsible-play messaging.
- `450d110` - Added BlockDrop ghost/hard drop, improved Chutes & Ladders positioning, and mobile touch steering for Worm 3D.
- `7b24d4e` - Replaced Worm with Kong Climber and made Neon Hopper D-pad controls permanent.
- `dd8af5f` - Added a Solana token scanner for momentum and liquidity-spike detection.
- `359960c` - Moved trading-bot work toward a standalone repository to keep Arcade Hub game-focused.
- `b7a41c9` - Added a prominent Trading Bot navigation tab and dashboard view back into Arcade Hub.
- `6fe4c23` - Connected the Trading Bot dashboard to CoinGecko market prices and polished flagship game mechanics.
- `f7e1130` - Added mobile swipe/flick gestures to skill games and synthesized casino audio for slots.
- `192d20b` - Added animated tile-by-tile Chutes & Ladders movement with step audio chimes.

### Versioning note

The project previously used patch-style displayed versions such as v0.0.31, v0.0.32, v0.0.33, and v0.0.34. Because 13 commits were made after the v0.0.34 bump without updating the displayed version, v0.0.47 is used as the reconciled version. No gameplay or application behavior is intentionally changed by this version/changelog update.
